# 재현 부탁드립니다

개발과 QA의 비밀 합주를 테마로 만든 4키 웹 리듬게임입니다.

## 실행

Node.js 22.13 이상에서 `npm ci`, `npm run dev -- --hostname 127.0.0.1` 순서로 실행합니다.
기본 주소는 http://127.0.0.1:5173 입니다. 현재 미리보기는 이 컴퓨터에서만 접근할 수 있습니다.

처음 멀티플레이를 실행하기 전에는 `npm run build` 후 로컬 대기실 스키마를 적용해야 합니다.

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_premium_supernaut.sql
```

위 초기 스키마는 한 번만 적용합니다. 운영 환경에 대한 명령이 아닙니다.

## 플레이

- 기본 키: D / F / J / K. 설정에서 각 레인을 누른 뒤 원하는 키를 지정합니다.
- 키 설정, 속도, 음량, ±200ms 타이밍 보정은 기기 내 브라우저 설정으로 저장됩니다.
- 솔로: 곡과 난이도를 선택해 시작합니다. 일시정지와 재개가 가능합니다.
- 협동/대결: 방을 만들고 7자리 코드를 공유합니다. 2–4명 모두 준비하면 방장이 시작합니다.
- 멀티에서는 모두 같은 곡과 난이도를 사용하고, 키·속도·음량·보정은 각자 설정합니다.
- 협동은 평균 정확도 80%를 목표로 합니다. 대결은 같은 채보의 점수를 비교합니다.
- 동시 시작은 서버 시각으로 맞추고 음악과 판정은 각 브라우저의 AudioContext 시계를 사용합니다.
- 점수는 약 1초마다 공유합니다. 참가자의 오디오는 네트워크로 전송하지 않습니다.
- 휴대폰에서는 화면 아래 네 개의 키를 터치할 수 있습니다. 키보드와 유선 이어폰을 권장합니다.

## 콤보 공격

멀티 협동과 대결에서 30콤보마다 공격권 1개를 얻고 최대 3개까지 보관합니다. 연속 콤보가 끊겨도 이미 얻은 공격권은 유지됩니다. 화면의 참가자 번호 1–4로 상대를 선택합니다. 내 번호는 공격할 수 없으며, 숫자키를 노트 키로 쓰는 경우 Shift+번호로 공격합니다. 터치/마우스로 상대 카드를 눌러도 됩니다.

공격은 무작위로 선택되며 1.8초 예고 후 8초 동안 적용됩니다.

- 긴급 검증: PERFECT ±40ms, GOOD ±100ms로 판정 강화.
- 추가 요구사항: 기존 박자 사이에 추가 노트 생성.
- 일정 당기기: 음악은 함께 유지하고 노트 낙하 속도만 1.45배 증가.
- 담당자 변경: 현재 네 키의 레인 배치를 반전. 종료 후 원래 설정으로 복구.

동일 효과는 중첩하지 않고 다른 종류를 우선합니다. 네 효과가 모두 걸려 있으면 추가 공격을 막습니다. 공격 간격은 2초이며 공격 요청 식별자로 중복 발사를 방지합니다. 원래 저장된 키 설정은 패널티가 변경하지 않습니다.

## 음원

외부 음원이나 샘플을 내려받지 않습니다. 기존 5곡은 이 프로젝트를 위해 작성한 멜로디·코드 진행·리듬을 Web Audio로 합성하고, 추가 4곡은 AI로 생성한 MP4 음원을 재생합니다. YouTube Music 한국 TOP20은 포함하지 않았습니다.

`lib/tracks.ts`: 곡별 BPM, 멜로디, 코드와 결정적 채보.
`lib/audio.ts`: MP4를 HTMLAudioElement로 재생하고 Web Audio 게인 노드에 연결하는 재생·시계 래퍼.

## 멀티 저장 및 접근

Cloudflare D1에 방 상태를 저장합니다. 2시간이 지난 방은 참여할 수 없으며, 데이터 자동 물리 삭제는 구성하지 않았습니다. 닉네임과 해당 방의 점수만 저장하고 계정 프로필이나 이메일을 수집하지 않습니다. 참가자 식별용 쿠키는 HttpOnly, SameSite=Strict이며 HTTPS에서는 Secure가 적용됩니다. 원본 쿠키는 데이터베이스나 로그에 기록하지 않습니다.

상태 갱신은 낙관적 버전 검사를 통해 동시 참가·준비 요청의 덮어쓰기를 방지합니다. 방장은 서버에서 검사하며, 요청 출처와 멤버 자격을 검사합니다. 점수는 브라우저가 제출하는 친선 게임용 점수이므로 변조 방지 경쟁 시스템은 아닙니다.

플랫폼의 비공개 접근 정책은 별도 배포 단계에서 설정해야 합니다. 방 코드는 사이트 전체의 접근 제한을 대체하지 않습니다. 현재 운영 배포 및 팀원 접근 허용은 수행하지 않았습니다.

## 검증

- `npx tsc --noEmit`: 타입 검사.
- `npm run build`: Cloudflare Worker 빌드.
- 개발 서버 실행 후 `node tests/rooms.mjs`: 동시 입장·준비, 4명 정원, 방장 권한, 동일한 시작 시각, 외부 출처 차단 검사. 테스트 자격증명은 메모리에만 유지합니다.
- `node tests/penalties.mjs`: 네 효과의 시간 경계, 키 복구, 추가 노트 충돌 검사.
- 개발 서버 실행 후 `node tests/attacks.mjs`: 공격권 획득·보관·소모, 4종 패널티, 예고·지속시간, 중복 요청·자기 공격·잘못된 라운드 검사.
- 실제 브라우저에서 노트 입력, PERFECT 판정, 키 중복 방지, 키 저장, 일시정지·재개, 곡 종료 후 결과 보고서를 확인했습니다. 멀티의 업무 누적 알림, 추가 노트, 판정 강화, 키 배치 반전과 종료 후 원상 복구도 브라우저에서 확인했습니다.

## 구현 범위

솔로와 협동/대결은 고정 채보 기반입니다. 플레이어가 직접 만든 새 패턴을 상대에게 보내는 편집 모드, 장기 랭킹, 실제 회사 계정 연동은 포함하지 않습니다.
